## What is in this repository
<One line for each of src/, tests/, data/, results/ and each file you wrote.>
- `src/`: Contains source code modules (`env_check.py` for environment inspection and `basics.py` for GC content calculations).
- `tests/`: Contains test suites (`test_visible.py` for provided checks and `test_lab01_own.py` for custom edge case tests).
- `data/`: Contains read-only input files (`qc_records.csv`).
- `results/`: Contains generated output files (`environment_report.txt`).
- `pytest.ini`: Configuration file for the pytest test runner.
- `requirements.txt`: Specified package dependencies for the project.
- `requirements-frozen.txt`: Pinned versions of installed packages recorded from `pip freeze`.
- `.gitignore`: Specifies intentionally untracked files and folders to exclude from version control.
- `AI_USE_LOG.md`: Log documenting interactions with AI tools according to course policy.
